# Иконология Бодуэна

Указатель и карточки статей «Иконологии» Чезаре Рипы во французском переводе Жана Бодуэна (Париж, 1644).

- `index.html` страница для просмотра на GitHub Pages
- `app.js`, `app.css` код и оформление, общие для GitHub Pages и Тильды
- `data/entries.json` все статьи: названия, страницы, переводы, описания гравюр
- `img/` гравюры, по одному файлу на статью (например `p1-1.jpg`)
