# Иконология Бодуэна

Указатель и карточки статей «Иконологии» Чезаре Рипы во французском переводе Жана Бодуэна (Париж, 1644).

- `index.html` страница для просмотра на GitHub Pages
- `app.js`, `app.css` код и оформление, общие для GitHub Pages и Тильды; переключатель языка RU/EN (`?lang=en`, `data-lang` на `div#iconologie`, запоминается)
- `data/entries.json` все статьи: названия (fr/ru/en), страницы, переводы, подпись на гравюре (`caption`, если отличается от названия), описания гравюр (`attrs`, с переводом `what_en`/`meaning_en`), расшифровка и перевод текста статьи (`text_fr`/`text_ru`/`text_en`), список файлов оригинала (`scans`)
- `img/` обработанные гравюры, по одному файлу на статью (например `p1-1.jpg`), светлый бумажный тон, без обрезки медальона
- `pages/` сканы страниц книги для раздела «Оригинал» в карточке (например `p1-002-1.jpg`), подгружаются только при открытии раздела
