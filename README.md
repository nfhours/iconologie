# Библиотека

Указатели и карточки статей старых книг, с переводом на русский и английский. Каждая книга — отдельная папка в `books/`.

- `index.html` страница для просмотра на GitHub Pages — без `data-book` показывает список всех книг
- `app.js`, `app.css` общий код и оформление для GitHub Pages и Тильды; переключатель языка RU/EN (`?lang=en`, `data-lang` на `div#iconologie`, запоминается); `data-book="<slug>"` на том же div закрепляет блок за одной книгой (так подключается Тильда)
- `library.json` реестр книг — список `{slug, path}`
- `motifs.json` общий закрытый словарь мотивов (рог изобилия, змея, венок…), книги ссылаются на него по `id`, не зная друг о друге
- `books/<slug>/book.json` метаданные книги: названия (ru/en/original), автор, год, части (`parts`, можно дополнять)
- `books/<slug>/entries.json` статьи этой книги: названия (fr/ru/en), страницы, переводы, подпись на гравюре (`caption`, если отличается от названия), описания (`attrs`, с переводом `what_en`/`meaning_en`), расшифровка и перевод текста (`text_fr`/`text_ru`/`text_en`), список файлов оригинала (`scans`), список мотивов (`motifs`, id из `motifs.json`)
- `books/<slug>/img/` обработанные гравюры/объекты, по одному файлу на статью
- `books/<slug>/pages/` сканы страниц книги для раздела «Оригинал», подгружаются только при открытии раздела
- `books/<slug>/_work/` рабочие файлы и необработанные сканы — не в репозитории (`.gitignore`)

## Адреса

- `#/<slug>/<id>` — карточка статьи; `#/<slug>` — указатель книги; `#/` или пусто — список книг (если блок не закреплён через `data-book`)
- старый формат без слага (`#/p1-3`, использовался до появления библиотеки) по-прежнему открывает нужную статью «Иконологии»

## Книги

- **iconologie** — «Iconologie» Чезаре Рипы в переводе Жана Бодуэна (Париж, 1644)
- **grosson** — «Recueil des Antiquités et Monumens Marseillois» Ж.-Б.-Б. Гроссона (Марсель, 1773) — в работе
